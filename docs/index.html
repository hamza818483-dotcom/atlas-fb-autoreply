Privacy Policy

Last updated: September 2026

This application ("ATLAS Reply") is a comment-automation tool used to reply to keyword-based comments on the ATLAS-Medical Preparation Facebook Page.

What we collect

When a user comments on a post on the connected Facebook Page, our system reads the comment text and the comment ID solely to determine if it matches a configured keyword. We do not collect, store, or share personal profile data, names, or any other identifying information about commenters.

How we use it

Matched comments receive an automatic public reply from the Page. No data is retained after the reply is sent, except operational logs kept for debugging purposes for a limited time.

Data sharing

We do not sell, rent, or share any data with third parties. Facebook/Meta Graph API is used only to post the reply back to the same comment thread.

Contact

For questions about this policy, please contact the Page admin via the ATLAS-Medical Preparation Facebook Page.
